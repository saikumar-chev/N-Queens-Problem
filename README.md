# N-Queens Solver with GUI

This project provides an interactive solution to the **N-Queens Problem** using a graphical user interface (GUI) built with Python's Tkinter library. It visualizes the process of placing queens on an `N x N` chessboard such that no two queens threaten each other.

---

## Features
- **Dynamic Input**: Enter any positive integer `N` to solve the N-Queens problem.
- **Real-Time Visualization**: Watch as queens are placed on the board step by step.
- **User-Friendly Interface**: Simple and clean design with a dark theme for better visual appeal.
- **Error Handling**: Displays appropriate messages for invalid or unsolvable inputs.

---

## How It Works
1. **Input**: Enter a value for `N` in the input box.
2. **Recursive Algorithm**: The program uses the backtracking algorithm to find a solution.
3. **Visualization**: The board updates dynamically as the algorithm tries different placements.
4. **Result**:
   - If a solution is found, a success message is displayed.
   - If no solution exists, an appropriate message is shown.

---

## Getting Started

### Prerequisites
- Python 3.x installed on your system.
- Tkinter library (comes pre-installed with Python).

### Installation
Run the program
`python main.py`

### Example Usage
1. Launch the program.
2. Enter a value for `N` (e.g., `8` for an 8*8 chessboard).
3. Click the **Solve** button.
4. Watch the placement of queens in real time!
